# SmetaPro — профессиональный тёмный рабочий кабинет

Интерфейс: тёмная графитово-синяя тема, боковая навигация, карточки показателей, редактор сметы и список сохранённых документов. Бренд SmetaPro сохранён.

## Запуск
- Для быстрой проверки откройте `index.html` в браузере.
- Для установки PWA и офлайн-кеша опубликуйте папку на HTTPS-статическом хостинге и откройте сайт онлайн один раз.
- После установки приложение открывается отдельно и может работать без интернета.

## Данные
Сметы хранятся в LocalStorage текущего браузера на текущем устройстве. Сервер, аккаунт и синхронизация не используются. Очистка данных сайта может удалить сметы. Регулярно используйте «Экспорт данных» и храните JSON-копию отдельно.

## Состав
- `index.html` — приложение
- `manifest.webmanifest` — настройки PWA
- `sw.js` — офлайн-кеш
- `icons/` — иконки приложения

## Будущая облачная версия
Архитектуру можно расширить синхронизацией через API и облачную БД, не меняя основной сценарий создания сметы.


## Возможности версии 2
- Отдельная локальная база клиентов и заказчиков.
- Каталог работ и материалов с демонстрационными ценами и добавлением позиций в смету.
- Сохранение реквизитов компании для фирменных документов.
- Печать сметы и счёта через браузер с сохранением в PDF.
- Резервная копия JSON включает сметы, клиентов, каталог и настройки бренда.

Цены каталога демонстрационные — замените их на актуальные перед использованием. Для PDF выберите в диалоге печати браузера «Сохранить как PDF». Данные хранятся локально в браузере.
